Игроки по серверам

Накопительная база всех персонажей, когда-либо встреченных armoury-скрапером — включая тех, кто с тех пор пропал с сайта. Каждый час база сверяется с текущим списком сайта: новые персонажи добавляются, у видимых сейчас обновляются данные, у пропавших последние известные данные остаются как есть. Клик по нику показывает историю его изменений.
